# 视图在逻辑 960×320 空间编写，物理方向隔离为帧缓冲变换适配器

TFT 面板物理最终横放（960×320），但当前真机是竖放（320×960）。所有视图统一在逻辑 960×320 横屏空间编排；逻辑坐标到 LT7680 原生帧缓冲的映射（当前为纯转置 `fb_x=uy; fb_y=ux`）收敛到单一变换适配器。物理方向变化只换适配器，视图零改动。

## Status

accepted

## Considered Options

- **逻辑 960×320 空间 + 单点变换适配器（选定）**：横放/竖放共用同一套视图代码，切换只改一个函数。反悔成本低。
- **视图直接按最终物理横放编写**：当前竖放真机只能靠软件旋转兜底，横放落定前每一版视图都要重写，且两套坐标系并存易错。
- **两套坐标系并存**：视图针对物理方向编程，代码重复，易在横放切换时漏改一处。

## Consequences

- 所有渲染代码只谈逻辑坐标；`lt7680_gfx_*` 之上的 UI 层不知道面板物理方向。
- 转置适配器负责边界钳位（960→320 / 320→960），未来 MADCTL/MACR 旋转也应在适配器内解决，不渗入视图。
