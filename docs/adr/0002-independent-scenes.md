# 读数场景常驻趋势视图

工业趋势 UI 将最近 10 秒趋势常驻在场景 0 的下部，同时保留趋势数据与场景生命周期解耦的纯数据模型。

## Status

Accepted (revised 2026-08-14 by the industrial trend UI decision)

## Considered Options

- **独立全屏场景（原选择）**：每个场景拿到完整画面，但操作员无法同时看到读数和近期变化。
- **读数页底部常驻趋势条（当前选择）**：密集工业布局仍保留 96px 主读数，并让趋势随时可见。
- **混合**：读数页常驻底部趋势条 + 独立全屏统计页：复杂度高于收益，两处趋势渲染路径重复。

## Consequences

- 场景 0 固定包含状态、功能、读数、参数和趋势五个区域。
- `trend_buffer` 仍是纯数据层，不随场景销毁，也不依赖 HAL 或显示控制器。
- 不增加本地场景导航；键盘透传语义保持不变。
