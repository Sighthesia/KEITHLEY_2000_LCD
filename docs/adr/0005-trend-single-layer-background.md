# ADR-0005: 趋势区单层背景

- 状态：已接受（2026-09-03）
- 背景：趋势区叠了 5 层底（面板 BAR、4px 分隔条、X 沟槽浅底、绘图黑底＋1px 内框）＋ Y 标签交替底板，视觉混乱且每次重建多耗约 7 次 GE 填充。

## 决策

- 只留一层底：面板 BAR 整区填充（统计条除外，其自有单元格）＋绘图区黑底。
- 删除：4px 分隔条、X 沟槽浅底、绘图区 1px 内框、Y 标签交替底板（标签直接落面板底上右对齐）。
- 保留两条 1px 发丝线（Y 轴右缘、X 轴顶缘）用于安置标签与绘图区的分界；网格、标签、统计栏、曲线逻辑不动。
- 布局常量（`PLOT_*`、`X_AXIS_*` 等）保持不变，只删填充不动几何，`verify.js` 几何断言继续有效。

## 影响文件

- `KEITHLEY_2000_LCD/Core/Src/main.c`（`reading_only_render_trend_background()` idx2 收敛为两条发丝线）
- `sim/index.html`（同步删层）
- `sim/verify.js`（新增单层背景＋发丝线断言）
