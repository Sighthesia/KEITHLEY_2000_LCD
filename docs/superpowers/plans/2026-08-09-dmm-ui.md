# K2000 DMM UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 STM32F103C8T6 + LT7680A-R 上实现现代台式万用表 UI(状态栏 + 7 位大数字 + 单位 + 次级统计 + 底部趋势图),从 K2000 协议读数流驱动。

**Architecture:** 单场景常驻 UI。逻辑组件(`k2000_proto`/`ui_model`/`trend_buf`/`reading_split`)为纯 C、双工程同步(firmware 骨架 + CubeMX 工程),用 host gcc 在 PC 单测;硬件组件(`hal_board` SPI1/UART/键盘、`lt7680_gfx` 几何原语、各 view 渲染)走真机验收。P0 三项前置修复(SPI1 硬件化、UART BRR、解析器状态 TAG)先行。

**Tech Stack:** STM32F103C8T6 (ARM Cortex-M3), STM32Cube HAL, LT7680A-R (SPI 控制 + 18-bit RGB), arm-none-eabi-gcc, host gcc (PC 单测), Python 3 + Pillow (字库生成), CMake/Ninja (CubeMX 工程), Makefile (firmware 骨架)。

## Global Constraints

- 目标 MCU:`STM32F103C8T6`,64KB Flash / 20KB RAM(链接脚本 `STM32F103xx_FLASH.ld`:RAM ORIGIN 0x20000000 LENGTH 20K)。
- 时钟:当前 HSI 8MHz、PLL 关闭、SYSCLK=HCLK=PCLK1=PCLK2=8MHz(不改动 SystemClock_Config)。
- 两个工程必须同步:`firmware/src/*` 与 `KEITHLEY_2000_LCD/Core/Src/*`、`Inc/*` 同名文件内容一致。改逻辑组件必须同步两份,两处构建都要过。
- firmware 骨架编译:`make -C firmware`,flags `-mcpu=cortex-m3 -mthumb -std=gnu11 -Os -Wall -Wextra -Werror -ffreestanding`。
- CubeMX 工程构建:`cmake --build KEITHLEY_2000_LCD/build/Release --target KEITHLEY_2000_LCD.elf`。
- 零告警(-Werror)。不得引入 C99 之后的新特性(gnu11)。
- 协议事实:`0x0D` 是消息起始/同步符;`0x04`=POS;`0x0B`=blink(参数 0x01 开始/0x00 结束);状态 TAG `0x06`(REM/TALK/LSTN/SRQ)、`0x07`(SHIFT/TIMER/MATH/REAR/diode/beep/4W/⇅)、`0x08`(HOLD/TRIG/FAST/MED/SLOW)、`0x09`(REL/FILT/AUTO/ERR/*/BUFFER/STAT)、`0x0A`(STEP/SCAN/CH1/CH2)、`0x0E`(CH3-CH10);每 TAG 的 bit 位映射 `0x80`=bit7 对应第一个指示符。
- 键盘矩阵:列=PB0..PB7(输出),行=PC13/PC14/PC15/PB10(输入上拉)。键码 `0x41`(SHIFT)..`0x60`(EXIT),`0x40`=all released。矩阵映射(ODS TX 表):PA0 行(现 PC13)=SHIFT/DCV/ACV/DCI/ACI/ohms2/ohms4/FREQ,PA1 行(现 PC14)=UP/AUTO/DOWN/ENTER/RIGHT/TEMP,PA2 行(现 PC15)=LOCAL/EXTTRIG/TRIG/STORE/RECALL/FILTER/REL/LEFT,PA3 行(现 PB10)=CALEN/OPEN/CLOSE/STEP/SCAN/DIGITS/RATE/EXIT。
- 大数字字库:JetBrains Mono 48×96,字符集 `0-9 . + - E e µ Ω k M V A` 等 ≈40 字符,1bpp,存 STM32 Flash(约 12KB)。
- 中文子集:仅静态标签(如"趋势图"等 ≤20 汉字),16×16,1bpp,存 STM32 Flash。协议不含中文。
- 趋势图:480 点窗口(2px/点)、`trend_buf` 512 点环形(float 值 + uint32 tick ≈4KB RAM)、自动量程 ±10% 边距、min/max 标签、满屏 BTE 左移 2 列。
- 采样触发:值变化必采样;值相同则距上次 ≥250ms 必采样。量级突变 >10× 清空缓冲。
- 特殊读数:`OVERFLOW` → 红字;`----` → 灰字;均不压入 trend_buf。
- 键盘发送:按下发键码、释放发 `0x40`,20ms 防抖,主循环轮询。
- 烧录:`openocd -f openocd.cfg -c "init" -c "halt" -c "program ...elf verify" -c "reset" -c "shutdown"`(`reset_config none`,不要 `program ... reset exit`)。
- 不要在本计划中提交任何未在任务中明确列出 commit 的更改。

```c
static void init_spi1(void)
{
    __HAL_RCC_SPI1_CLK_ENABLE();
    SPI1->CR1 = 0;
    /* CPOL=0, CPHA=0 (mode 0), master, 8-bit, MSB first, /2 prescaler.
     * PCLK2 = 8MHz -> SPI clock = 4MHz. */
    SPI1->CR1 = SPI_CR1_MSTR | SPI_CR1_SSI | SPI_CR1_SSM |
                (SPI_CR1_BR_0); /* BR = 001 -> fPCLK/2 */
    SPI1->CR2 = 0;
    SPI1->CR1 |= SPI_CR1_SPE;
}
```

```c
    }
    SPI1->DR = byte;
    while ((SPI1->SR & SPI_SR_RXNE) == 0u) {
    }
    return (uint8_t)SPI1->DR;
}
```

```c
static void init_uart(void)
{
```

- [ ] **Step 2: 实现 LT7680 几何原语**

LT7680 画线寄存器(按 LT768x DS V4.2 几何引擎):DCR0=REG[67h](bit7 开始、bit6 填充、bit[4:1] 命令),起点 REG[68h..6Bh](GE_SPT,13-bit x/y),终点 REG[6Ch..6Fh](GE_EPT)。画线命令需查 DS 确认 DCR0 命令编码(线=与矩形不同)。**实现时必须查 LT7680 数据手册/AP-Note 确认 DCR0 命令值**,不要猜测。画线颜色用现有 `set_fg_color16`。

`firmware/src/lt7680_gfx.c` 追加(签名与 DS 核对):

```c
lt7680_status_t lt7680_gfx_draw_line(int16_t x0, int16_t y0,
                                     int16_t x1, int16_t y1,
                                     uint16_t rgb565)
{
    if (x0 < 0 || y0 < 0 || x1 < 0 || y1 < 0) {
        return LT7680_ERR_PARAM;
    }
    lt7680_status_t st = set_fg_color16(rgb565);
    if (st != LT7680_OK) {
        return st;
    }
    /* Select line command in DCR0, then write start/end points, then draw. */
    st = wr(REG_DCR0, 0x00u);  /* select draw line command */
    if (st != LT7680_OK) {
        return st;
    }
    st = wr32le(REG_GE_SPT, ((uint32_t)x0 & 0x1FFFu) |
                            (((uint32_t)y0 & 0x1FFFu) << 16));
    if (st != LT7680_OK) {
        return st;
    }
    st = wr32le(REG_GE_EPT, ((uint32_t)x1 & 0x1FFFu) |
                            (((uint32_t)y1 & 0x1FFFu) << 16));
    if (st != LT7680_OK) {
        return st;
    }
    /* DCR0: bit7=start, no fill, line command (查 DS 确认编码). */
    return wr(REG_DCR0, 0x80u | /* line cmd bits */ 0x00u);
}
```

`draw_polyline` 循环调 `draw_line` 相邻点;`draw_circle` 用几何引擎圆命令(查 DS DCR0 圆编码),或退化为逐点 Bresenham(MCU 侧画到 SDRAM,`lt7680_gfx_set_pixel`)。**首版实现优先用 LT7680 硬件几何;若 DS 无法及时核对,DCR0 命令编码以数据手册为准,先实现 draw_line(趋势图必需),draw_circle 可延后到 P1 验收后。**

```python
#!/usr/bin/env python3
"""Rasterize JetBrains Mono TTF into 1bpp C arrays for the K2000 UI.

Usage: python3 make_digit_font.py <jetbrains-mono-regular.ttf> <out_dir>
Outputs font_digits.c and font_digits.h (48x96 px, 1bpp, MSB first per row).
Charset is fixed: "0123456789.+-Ee%mukKMWVOhDAC" (adjust to spec).
"""
import sys
from PIL import Image, ImageDraw, ImageFont

W, H = 48, 96
CHARSET = "0123456789.+-Ee%mukKMWVOhDAC"

def main():
    ttf, out_dir = sys.argv[1], sys.argv[2]
    font = ImageFont.truetype(ttf, size=H)
    glyphs = {}
    for ch in CHARSET:
        img = Image.new("1", (W, H), 0)
        d = ImageDraw.Draw(img)
        d.text((0, 0), ch, font=font, fill=1)
        glyphs[ch] = img
    # emit C arrays (each char 576 bytes, one bitmap per char, MSB first)
    header, body = [], []
    body.append(f"static const uint8_t s_digit_bitmaps[{len(CHARSET)}][{W*H//8}] = {{")
    for ch in CHARSET:
        bmp = glyphs[ch]
        bits = bmp.tobytes()  # mode "1" rows already packed
        body.append("    /* '%s' */" % ch)
        body.append("    {" + ",".join(f"0x{b:02X}" for b in bits) + "},")
    body.append("};")
    # ... emit font_digit_bitmap(), font_digit_width(), font_digit_height()
    # header with prototype + charset index mapping
    ...
```

`keypad_scan`:参数化传入"当前按下键码"(由 HAL 层轮询矩阵获得),内部做 20ms 防抖与边沿:

```c
int keypad_scan(keypad_t *k, int raw_code, uint32_t tick_ms);
```
- `raw_code` = 当前检测到的键(0 = 无键)。
- 若 `tick_ms - k->last_tick < 20` 且键未变:返回 0(防抖中)。
- 键变化:`k->last_code != raw_code` → 若 raw_code>0 返回 raw_code(按下),若 raw_code==0 且旧键>0 返回 0x40(释放)。
- 更新 last_code/last_tick。

`test_keypad.c` 追加防抖用例:

```c
/* Debounce: same key within 20ms not re-emitted. */
keypad_t k; keypad_init(&k);
assert(keypad_scan(&k, 0x41, 0) == 0x41);   /* press */
assert(keypad_scan(&k, 0x41, 10) == 0);      /* debounce, still held */
assert(keypad_scan(&k, 0x41, 30) == 0);      /* held, no repeat */
assert(keypad_scan(&k, 0, 40) == 0x40);      /* release -> 0x40 */
```
