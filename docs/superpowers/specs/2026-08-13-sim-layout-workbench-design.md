# 仿真器无滚动布局工作台设计

## 修订记录

- 2026-08-13：目标视口由 `1366×768` 调整为 `1920×1080`。主屏恢复 1:1 像素显示
  （960×320），帧缓冲缩略图放大为 160×480，场景控制默认展开。

## 目标

重构 `sim/index.html` 的布局编辑界面，使它在 `1920×1080` 桌面视口中无需页面滚动，
并将当前以画布拖拽为主的编辑方式替换为直接、精确的数值参数编辑。

编辑任意参数后，主屏画布和帧缓冲预览必须立即重绘。默认参数必须继续与
`main_display.h` 一致，`node sim/verify.js` 必须保持通过。

## 工作台布局

页面使用固定高度的双栏工作台：

- 顶部标题栏保持单行且紧凑。
- 左栏为预览区，占据可用宽度。主屏画布以 1:1 像素显示（960×320），
  帧缓冲预览为主屏右侧的 160×480 缩略图。
- 右栏为约 `430px` 宽的控制台，使用紧凑行高并固定在首屏内，场景控制默认展开。
- 在视口小于设计目标时，控制台或预览区允许自身滚动；桌面页面本身不产生滚动条。

## 参数编辑

移除作为主要工作流的元素列表、坐标卡和画布缩放按钮。保留画布叠加层，仅在选择的
参数对应区域显示边界，帮助确认该参数影响的图形位置。

参数面板使用分组表格。每一行包含参数名称、数值输入、减一按钮、加一按钮和 `px`
或 `slots` 单位。所有输入使用整数并限定有效范围，按钮与直接输入共用同一更新路径。

分组和参数如下：

| 分组 | 参数 |
| --- | --- |
| 垂直布局 | `topBandH`、`sepH`、`readingH` |
| 光标 | `cursorGap`、`cursorH` |
| 顶部文本 | `unitPadX`、`statusPadX`、`statusGap` |
| 无数据占位 | `noDataSlots`、`noDataDX`、`noDataDY` |

选中某一参数时，画布仅突出显示对应元素。多个参数共享同一元素时，选择任一参数均突出
该元素，例如 `topBandH` 和 `sepH` 对应顶部区域与分隔线。

## 场景与导出

读数输入、特殊态、光标、状态指示和预设继续保留，但重新排成紧凑的两列或网格布局。

导出区默认仅显示“复制 C 宏”和“重置布局”命令及短状态文本。导出的宏文本收纳在
`details` 内，只有用户展开时才占据空间。复制通过现代 Clipboard API 完成，并在不可用
时回退到现有的文本选择复制方式。

`#define` 导出格式保持与现有版本相同，非 `main_display.h` 的偏移量继续以注释形式导出。

## 兼容性与验证

- `render()` 仍以 `L` 为唯一可变布局模型；参数控件仅通过受限赋值更新 `L`。
- 需保留无头环境保护：`sim/verify.js` 不提供真实 overlay canvas 或完整 DOM，devtools
  初始化和 DOM 写入必须可安全跳过。
- 更新 `sim/README.md`，说明直接参数编辑、选择提示和导出方式。
- 验收命令为 `node sim/verify.js`。同时以最小 DOM mock 运行布局参数冒烟检查，至少覆盖：
  数值更新、范围裁剪、重置、导出与无头环境加载。

## 非目标

- 不修改固件的 `main_display.h`、`main_display.c` 或任何硬件显示逻辑。
- 不新增持久化布局配置、文件导入或历史撤销栈。
- 不以画布拖拽作为主要精调方式。
