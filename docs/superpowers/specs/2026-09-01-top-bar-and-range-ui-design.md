# 顶栏与档位 UI 重整设计

## 目标

重整 960x320 逻辑 UI 的顶部两行，同时保持读数区和趋势区的既有几何、协议模型和双页渲染机制不变。

## 布局

- 第一行保持 24px 高：左侧固定显示 `KEITHLEY 2000`，右侧显示内部温度和运行时间，格式为 `xx.x°C  HH:MM:SS`。
- 第一行中间只显示当前激活的状态标签；没有激活状态时中间区域为空。状态标签从现有协议状态模型聚合，不再显示 inactive 标签、BUFFER 长文本或 GPIB 占位文本。
- 第二行保持 26px 高：不绘制顶部或底部描边。
- 第二行左侧显示当前档位名称，按两行垂直居中排版，例如 `DC` / `VOLTAGE`；名称来源于现有 `ui_function_t` 映射。
- 读数区仍从 y=50 开始，趋势区仍从 y=192 开始，避免改变已验证的数字字形和趋势坐标。

## 数据流

- STM32F103 内部温度通过 ADC1 通道 16 采样。使用 `VREFINT` 与芯片温度校准常量换算摄氏度，采样失败时显示 `--.-°C`。
- 运行时间直接由 `HAL_GetTick()` 转换为小时、分钟、秒；离线骨架使用宿主 tick 接口，仿真器使用页面运行时间。
- 温度和运行时间属于显示快照字段，只有内容变化时重绘顶栏，避免每个主循环都触发整行 GE 绘制。

## 同步范围

`firmware/src` 是逻辑镜像源；对应文件同步到 `KEITHLEY_2000_LCD/Core`。`sim/index.html` 和 `sim/verify.js` 使用相同的 y 坐标和文本语义。现有趋势、读数、RIF 字形和协议测试继续作为回归检查。

## 验收

- 仿真器首屏可见品牌、动态温度、运行时间和两行档位名称。
- 状态关闭时第一行中间不留灰色占位标签；状态激活时只出现激活标签。
- 第二行不存在横向描边，档位两行在 26px 行内垂直居中。
- `firmware/tests/run_tests.sh`、`node sim/verify.js` 和 CubeMX Release ELF 构建通过。
