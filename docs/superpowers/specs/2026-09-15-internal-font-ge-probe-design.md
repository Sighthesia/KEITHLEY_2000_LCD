# 内部字体 GE 探针设计

日期：2026-09-15

## 目标

在不依赖外部字体 BIN、RIF、Flash DMA、SDRAM glyph cache 或 BTE 的条件下，验证 LT7680 的 GE 填充、Canvas 坐标和内部 1bpp 字体解析是否能稳定显示字形。

首个探针只显示内部 `font_text` 中的 ASCII `8`。该探针是诊断路径，不替换现有 RIF 产品路径。

## 范围

包含：

- 增加 `K2000_INTERNAL_FONT_PROBE` 编译开关，默认值为 `0`。
- 增加一个内部字体 GE 绘制函数：读取现有 1bpp 字模，按行提取连续前景像素段。
- 每个前景段使用现有 GE 矩形填充 API 绘制；背景由调用方先清除或由现有页面背景提供。
- 通过固定坐标绘制单个 ASCII `8`，使用现有 UI 前景色和背景色。
- 纯逻辑树和 CubeMX 树保持共享逻辑一致。
- 增加宿主测试，覆盖位序、前景段合并、空行和边界坐标。

不包含：

- 不修改 RIF header、directory、payload 或几何规则。
- 不生成、烧录或解析新的字体 BIN。
- 不调用外部 Flash、Flash DMA、SDRAM glyph cache 或 BTE。
- 不在第一阶段接入 `font_digits` 大字体、双页提交、趋势图或动态读数。
- 不改变默认产品行为；探针关闭时现有 RIF 路径不变。

## 数据流

```text
font_text 的 1bpp 字模
    -> CPU 按 MSB-first 提取每行前景段
    -> LT7680 GE Fill Rect
    -> 当前 Canvas/page
```

字模坐标约定沿用现有字体源：行 0 在顶部，最高位对应最左像素。每行相邻的前景位合并为一个矩形段，以减少 GE 操作次数；空行不产生操作。

## 运行时开关

`K2000_INTERNAL_FONT_PROBE` 默认关闭并在编译期选择路径：

- `0`：保留现有 RIF/外部资源渲染流程。
- `1`：在固定诊断场景中绘制单个 ASCII `8`，跳过 RIF 字形绘制，不启动外部字形 DMA/BTE。

探针模式仍使用正常 LT7680 初始化和 GE Canvas 配置；它不能绕过面板初始化、Canvas 设置或 GE busy 等待。UART 日志和 demo feed 继续遵守现有默认关闭约束。

## 错误处理

- 本固定坐标 ASCII `8` 探针使用已确认落在 UI bounds 内的 `(32,48)`；本阶段不把
  `ui_draw_bitmap_slice()` 扩展为通用矩形边界验证器。空指针、未知字符和零尺寸字模
  的通用约束仍由现有字体 API 保持，不作为本探针的硬件验收结论。
- 任一 GE 操作失败立即停止当前字形，保留原始错误状态，不提交看似完整的探针帧。
- 探针失败不得回退到 RIF DMA/BTE；这样可以保持诊断结论的隔离性。

## 测试与验收

宿主测试应证明：

1. `8` 的 MSB-first 位序转换正确。
2. 连续前景位合并为最少的水平段，空行不产生段。
3. 首列、末列和单像素段边界正确。
4. 非法字符不会产生额外 GE 调用；固定 `(32,48)` 探针坐标由现有面板尺寸和
   `12x24` 字模尺寸确认安全，不声称通用越界矩形验证。
5. 探针关闭时现有 RIF 构建和测试行为不变。

硬件验收分阶段进行：

1. GE 纯色整屏 Fill 无黑块和花屏。
2. 内部 `font_text` 单个 `8` 静态显示正确。
3. 保持单页、无动态刷新，确认字形方向、颜色和边界。
4. 只有探针静态显示通过后，才评估 `font_digits` 大字体和动态页面。

## 后续扩展边界

第一阶段通过后，可在独立变更中增加 `font_half` 和 `font_digits` 适配；仍应先保持单页静态显示，再逐步打开动态刷新和双页。任何外部 RIF/BIN 结论必须与该内部字体基线分开记录。
