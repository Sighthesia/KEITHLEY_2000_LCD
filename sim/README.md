# K2000 工业趋势 UI 仿真器

浏览器中逐像素预览 960×320 常驻读数与 10 秒趋势界面，以及转置后的
320×960 帧缓冲。直接打开 `sim/index.html`，或运行静态文件服务器。

默认完整设计预设为 `+03.68900 V`、10V AUTO、MOVING 10、GPIB 16，带
确定性的 RC/锯齿趋势。范围、滤波细节和 GPIB 地址属于**仿真场景输入**，
不表示 Keithley 面板协议提供这些信息；目标固件对此显示精简未知形式。

验证：

```sh
node sim/verify.js
```

验证覆盖五区总高度、固定 X 轴标签、240 列趋势预算、认证状态术语、禁用
DMM6500 术语，以及无 DOM 加载安全性。
